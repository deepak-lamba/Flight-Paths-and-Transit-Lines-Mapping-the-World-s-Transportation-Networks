# Flight-Paths-and-Transit-Lines-Mapping-the-World-s-Transportation-Networks
Mapping - Transit Systems and Airports 

## World Airports Data:
- **Source:** The world airports dataset was obtained from Kaggle and is available as a single file named "World_Airports.csv".
- **Content:** This dataset contains comprehensive information about airports worldwide, including code names, elevation, frequency, runway length, runway width, location, country, and Wikipedia links.
- **Origin:** The dataset can be accessed on Kaggle via the following URL: [World Airports Dataset on Kaggle](https://www.kaggle.com/datasets/mexwell/world-airports).
- **Scope:** It covers airports from various countries and regions across the globe, providing detailed attributes essential for analyzing air transportation networks.

## Transit Systems of the World:
- **Source:** The transit systems dataset was obtained from Kaggle and comprises multiple files obtained from the collaborative mapping platform, citylines.co.
- **Content:** The dataset includes transportation line data from numerous cities worldwide, such as London, Berlin, Mexico City, Barcelona, Washington D.C., among others. It covers thousands of kilometers of transit lines, including information on cities, lines, stations, systems, and tracks.
  - **Files:** The dataset is distributed across seven files:
    - **cities.csv:** Includes information about cities such as name, start year, country, and location.
    - **lines.csv:** Contains data on transit lines, including line ID, city ID, name, and associated systems.
    - **station_lines.csv:** Provides details about station IDs, line IDs, and city IDs.
    - **stations.csv:** Lists stations along with corresponding line IDs, names, geometry, and dates.
    - **systems.csv:** Includes information about transit systems and their corresponding city IDs.
    - **track_lines.csv:** Contains data on track IDs, section IDs, line IDs, and city IDs.
    - **tracks.csv:** Lists tracks along with corresponding line IDs, geometry, and dates, including track length.
- **Origin:** The dataset can be accessed on Kaggle via the following URL: [Transit Systems of the World Dataset on Kaggle](https://www.kaggle.com/datasets/citylines/city-lines).
- **Features:** Users can explore geometries to generate maps and analyze historical records to observe changes in transit lines over time, making it a valuable resource for studying transportation infrastructure and urban mobility.
